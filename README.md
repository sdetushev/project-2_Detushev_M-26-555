# Примитивная база данных

Консольное приложение на Python для создания таблиц и управления записями.

Приложение поддерживает основные CRUD-операции: добавление, просмотр,
изменение и удаление записей.

## Запуск

Запуск приложения через `uv`:

```bash
uv run database
```

## Управление таблицами

Приложение позволяет создавать, просматривать и удалять таблицы.

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `info <имя>` | Показать структуру таблицы и количество записей |
| `help` | Показать справку |
| `exit` | Выйти из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`,
если он не указан пользователем.

Пример создания таблицы:

```text
create_table users name:str age:int is_active:bool
```

## Работа с записями (CRUD)

### Добавление записей — INSERT

```text
insert into users values ("Sergei", 28, true)
```

При добавлении записи автоматически генерируется уникальный
идентификатор `ID` на основе существующих записей.

Количество значений и их типы должны соответствовать структуре таблицы.

### Просмотр записей — SELECT

Просмотр всех записей:

```text
select from users
```

Просмотр записей с условием:

```text
select from users where age = 28
```

Результаты выводятся в виде таблицы с помощью библиотеки `PrettyTable`.

### Изменение записей — UPDATE

```text
update users set age = 29 where name = "Sergei"
```

Команда изменяет записи, удовлетворяющие условию `WHERE`.

Тип нового значения должен соответствовать типу столбца.
Изменение служебного столбца `ID` запрещено.

### Удаление записей — DELETE

```text
delete from users where ID = 1
```

Команда удаляет записи, удовлетворяющие условию `WHERE`.

### Информация о таблице — INFO

```text
info users
```

Команда показывает название таблицы, её столбцы с типами данных
и количество сохранённых записей.

## Хранение данных

Метаданные таблиц сохраняются в файле `db_meta.json`.

Записи каждой таблицы сохраняются отдельно в формате JSON:

```text
data/
    users.json
```

При повторном запуске приложения сохранённые записи загружаются
из соответствующих файлов.

При удалении таблицы удаляются её метаданные и файл с записями.
