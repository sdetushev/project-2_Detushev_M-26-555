# Примитивная база данных

Консольное приложение на Python для создания таблиц и управления записями.

Приложение поддерживает основные CRUD-операции: добавление, просмотр,
изменение и удаление записей.

## Установка и запуск

Для работы с проектом необходимы Python 3.12 или новее и менеджер пакетов `uv`.

Склонируйте репозиторий:

```bash
git clone git@github.com:sdetushev/project-2_Detushev_M-26-555.git
cd project-2_Detushev_M-26-555
```

Установите зависимости:

```bash
make install
```

Запустите приложение:

```bash
make run
```

Для проверки качества кода выполните:

```bash
make lint
```

Также можно использовать команды `uv` напрямую:

```bash
uv sync
uv run database
uv run ruff check .
```

## Управление таблицами

Приложение позволяет создавать, просматривать и удалять таблицы.

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `info <имя>` | Показать структуру таблицы и количество записей |
| `help` | Показать справку |
| `exit` | Выйти из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется служебный столбец `ID:int`.
Пользователь не может самостоятельно объявлять или изменять этот столбец.

Пример создания таблицы:

```text
create_table users name:str age:int is_active:bool
```

## Работа с записями (CRUD)

### Добавление записей — INSERT

```text
insert into users values ("Sergei", 28, true)
```

При добавлении записи автоматически генерируется уникальный
идентификатор `ID` на основе существующих записей.

Количество значений и их типы должны соответствовать структуре таблицы.

### Просмотр записей — SELECT

Просмотр всех записей:

```text
select from users
```

Просмотр записей с условием:

```text
select from users where age = 28
```

Результаты выводятся в виде таблицы с помощью библиотеки `PrettyTable`.

### Изменение записей — UPDATE

```text
update users set age = 29 where name = "Sergei"
```

Команда изменяет записи, удовлетворяющие условию `WHERE`.

Тип нового значения должен соответствовать типу столбца.
Изменение служебного столбца `ID` запрещено.

### Удаление записей — DELETE

```text
delete from users where ID = 1
```

Команда удаляет записи, удовлетворяющие условию `WHERE`.

Перед удалением программа запрашивает подтверждение пользователя.

### Информация о таблице — INFO

```text
info users
```

Команда показывает название таблицы, её столбцы с типами данных
и количество сохранённых записей.

## Хранение данных

Метаданные таблиц сохраняются в файле `db_meta.json`.

Записи каждой таблицы сохраняются отдельно в формате JSON:

```text
data/
    users.json
```

При повторном запуске приложения сохранённые записи загружаются
из соответствующих файлов.

При удалении таблицы удаляются её метаданные и файл с записями.

## Декораторы и замыкания

Для обработки ошибок, подтверждения удаления, измерения времени выполнения
и кеширования запросов используются декораторы и замыкания.

### Обработка ошибок

Декоратор `handle_db_errors` перехватывает исключения `KeyError`,
`ValueError` и `FileNotFoundError` и выводит соответствующие сообщения
без аварийного завершения программы.

### Подтверждение удаления

Декоратор `confirm_action` запрашивает подтверждение перед удалением
таблицы (`drop_table`) или записей (`delete`).

Пример:

```text
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
```

При вводе `y` операция выполняется. При любом другом ответе
удаление отменяется.

### Измерение времени выполнения

Декоратор `log_time` измеряет время выполнения функций `insert`
и `select` с помощью `time.monotonic()`.

Пример:

```text
Функция select выполнилась за 0.000 секунд.
```

### Кеширование запросов

Функция `create_cacher()` создаёт замыкание для хранения результатов
вычислений по ключу.

Кеширование применяется к функции `select`: при повторном запросе
с теми же данными и условием `WHERE` используется сохранённый результат.

После операций `insert`, `update` и `delete` кеш очищается,
чтобы последующие запросы возвращали актуальные данные.
